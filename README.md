# Nav-Mboa-app
A Flutter-based tourism application with a FastAPI backend, designed to help users explore destinations, discover attractions, and access useful travel information.Nav_app

Nav_app is a Flutter-based tourism application designed to help users explore destinations, discover attractions, and access useful travel information. It combines a mobile-friendly interface with a FastAPI backend to support its application features.

Features

- Cross-platform development: Built with Flutter for multiple platforms.
- Backend integration: Uses FastAPI for backend services.
- Tourism and exploration: Designed to help users discover destinations and attractions.
- Structured architecture: Separates the Flutter frontend from the backend.

Technologies Used

- Flutter – Cross-platform application development.
- Dart – Main programming language for the Flutter application.
- Python – Backend programming language.
- FastAPI – Backend framework.
- Git and GitHub – Version control and source code management.

Getting Started

Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK (included with Flutter)
- Python
- Git
- Visual Studio Code or another compatible IDE

Installation

1. Clone the repository

git clone https://github.com/Vanbrown99/Nav_app.git

2. Navigate to the project directory

cd Nav_app

3. Install Flutter dependencies

flutter pub get

4. Run the application

flutter run

Backend Setup

Navigate to the backend directory:

cd backend

Install the backend dependencies using the project's dependency file and follow the backend configuration instructions.

Start the FastAPI application using the appropriate entry point and server command for the project.
